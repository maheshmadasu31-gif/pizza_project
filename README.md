# 🍕 Python Pizza Order Calculator
 
A simple command-line **Pizza Order and Bill Calculator built with Python**.
 
This beginner Python project simulates a basic pizza ordering system. The user selects a pizza size and optional toppings, and the program automatically calculates the final bill based on their choices.
 
## 🚀 Features
 
- Choose between Small, Medium, and Large pizzas
- Add pepperoni as an optional topping
- Add extra cheese
- Automatically calculates the final price
- Uses different pepperoni prices depending on pizza size
- Detects an invalid pizza size
- Displays the final bill to the customer
 
## 🛠️ Technologies Used
 
- Python 3
- Conditional statements
- Nested `if` statements
- `if`, `elif`, and `else`
- User input
- Variables
- Basic arithmetic
- String formatting with f-strings
